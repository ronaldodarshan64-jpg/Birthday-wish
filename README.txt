BHOOMI BIRTHDAY WEBSITE
=======================

1. Extract this ZIP file.
2. Open the Bhoomi-Birthday folder in Visual Studio Code.
3. Open index.html in your browser, or use the Live Server extension.
4. Your seven uploaded photos are already included in the images folder.

CUSTOMISING
-----------
- Edit the birthday message in index.html.
- Replace images/photo1.jpg ... photo7.jpg to change the gallery photos.
- The site currently uses animated visual effects and does not require a music file.
- If you want background music, tell me and I can add a music player with your chosen audio file.

PUBLISHING
----------
You can publish this folder using GitHub Pages:
1. Create a GitHub repository.
2. Upload all files and the images folder.
3. In repository Settings > Pages, choose Deploy from a branch.
4. Select the main branch and root folder, then Save.
5. GitHub will provide the website link when deployment finishes.
